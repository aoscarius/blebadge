About this app

Requirements: Chrome or Edge, desktop or Android, served over HTTPS or localhost (Web Bluetooth won't work over plain http:// or on iOS Safari).


Protocol: this talks directly to the badge's GATT service (advertised UUID 0xFFE0) using the write characteristic 0xA951 for commands and 0xA952 for brightness/speed buffers, exactly as reverse-engineered in your pyHack.py capture.


Text & Free Draw both work by rasterizing content to a 12×48 bitmap in the browser and pushing it pixel-by-pixel through Free Draw mode (0x0301… + per-pixel 0x0302… writes) — the same mechanism your pyFreeDraw.py used. The device's own proprietary "upload custom font" packet format (seen commented out in pyHack.py) wasn't fully reverse-engineered, so it isn't used here; instead, long text can be scrolled from the browser side by re-sending shifted frames — enable "Software scroll" on the Text tab.


Animations (0–18) and the Audio Spectrogram mode use the manufacturer's built-in device commands directly.


Free Draw sends ~576 individual BLE writes per frame (one per pixel), so each send takes a couple of seconds — this matches the timing your original scripts used.
